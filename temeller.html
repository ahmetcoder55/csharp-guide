1. Temel Tipler ve Bellek Yönetimi

C# dilinde veriler Stack veya Heap üzerinde saklanmalarına göre ikiye ayrılır.

Value Types vs Reference Types
// Value Types (Stack)
int age = 25;
double price = 199.99;
bool isActive = true;

// Reference Types (Heap)
string name = "Ahmet";
int[] numbers = { 1, 2, 3 };
Pattern Matching (Switch Expression)
string GetCategory(int age) => age switch
{
    < 13 => "Çocuk",
    >= 13 and < 20 => "Genç",
    _ => "Yetişkin"
};
